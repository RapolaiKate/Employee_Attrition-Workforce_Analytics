# Employee Attrition & Workforce Analytics Dataset

## 📊 Dataset Overview

This folder contains the datasets used for the **Employee Attrition and Workforce Analytics** project.

The dataset contains employee-level workforce information that can be used to analyze **employee attrition, job satisfaction, compensation, performance, overtime, work-life balance, and other workforce characteristics**.

---

## 📁 Dataset Files

### Raw Dataset

The raw dataset is the original version of the data before any cleaning or transformation.

**File:**

```text
employee_attrition_raw.csv
```

### Cleaned Dataset

The cleaned dataset is the prepared version used for further analysis, SQL queries, and visualization.

**File:**

```text
employee_attrition_cleaned.csv
```

---

## 📌 Dataset Size

* **Rows:** 10,000
* **Columns:** 14

---

## 📋 Dataset Columns

| Column                   | Description                                                                |
| ------------------------ | -------------------------------------------------------------------------- |
| Employee ID              | Unique identifier for each employee                                        |
| Age                      | Employee age                                                               |
| Department               | Department where the employee works                                        |
| Job Level                | Employee's job level                                                       |
| Years at Company         | Number of years the employee has worked at the company                     |
| Monthly Income           | Employee's monthly income                                                  |
| Job Satisfaction         | Employee job satisfaction rating                                           |
| Work-Life Balance        | Employee work-life balance rating                                          |
| Overtime                 | Indicates whether the employee works overtime                              |
| Distance From Home       | Distance between the employee's home and workplace                         |
| Promotion Last 5 Years   | Indicates whether the employee received a promotion in the last five years |
| Performance Rating       | Employee performance rating                                                |
| Training Hours Last Year | Number of training hours completed during the previous year                |
| Attrition                | Indicates whether the employee left the company                            |

## 🔄 Data Preparation

The raw dataset was inspected and prepared using **Python and Pandas**.

The preparation process included:

* Checking the dataset structure
* Checking data types
* Checking for missing values
* Checking for duplicate records
* Reviewing numerical statistics
* Validating categorical values
* Preparing the cleaned dataset for analysis

---

## 🎯 Purpose of the Dataset

The dataset is used to investigate questions such as:

* What factors are associated with employee attrition?
* Which departments have higher employee turnover?
* How does overtime relate to attrition?
* Does job satisfaction differ between employees who stay and leave?
* How do income and job level relate to employee retention?
* What workforce characteristics can help HR improve employee retention?
